Política de Privacidade

Última atualização: 26 de junho de 2026

A NOVAIX Fitness valoriza a privacidade dos seus usuários. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos suas informações pessoais, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

1. Dados Pessoais Coletados

1.1 Dados de Cadastro

  • Nome completo
  • Endereço de e-mail
  • Senha (armazenada de forma criptografada)
  • Foto de perfil (opcional)

1.2 Dados Físicos (Onboarding)

  • Gênero
  • Data de nascimento
  • Altura e peso
  • Tipo corporal
  • Nível de experiência
  • Disponibilidade de treino
  • Tipo de academia
  • Objetivo de treino

1.3 Dados de Uso

  • Historórico de treinos completados
  • Tempo de exercício
  • Avaliações e comentários
  • Medidas corporais (quando fornecidas)
  • Fotos de progresso
  • Dados de peso ao longo do tempo

1.4 Dados Técnicos

  • Token de notificação push
  • Configurações do aplicativo
  • Dados de conexão (offline/online)

2. Finalidade do Tratamento

Seus dados são utilizados para:

  • Personalização: Criar treinos adaptados ao seu perfil e objetivos
  • Funcionamento: Operar o App, autenticar sua conta e processar pagamentos
  • Notificações: Enviar lembretes de treino, atualizações e comunicações relevantes
  • Melhoria: Analisar uso do App para melhorar funcionalidades
  • Suporte: Responder dúvidas e resolver problemas
  • Comunidade: Permitir interação com outros usuários
  • Legal: Cumprir obrigações legais e regulatorias

3. Base Legal para o Tratamento

O tratamento dos seus dados é realizado com base em:

  • Consentimento: Quando você autoriza coleta de dados opcionais
  • Execução de contrato: Para fornecer os serviços contratados
  • Legítimo interesse: Para melhorar o App e prevenir fraudes
  • Obrigação legal: Para cumprir exigências fiscais e regulatorias

4. Compartilhamento de Dados

Não vendemos seus dados pessoais.

Seus dados podem ser compartilhados apenas com:

  • Provedores de pagamento: Asaas, para processar transações de assinatura
  • Infraestrutura: Supabase (banco de dados e armazenamento) e Expo (notificações push)
  • Análises: Dados agregados e anônimos para melhoria do produto
  • Google: Para autenticação (Google Sign-In) e analytics

Todos os provedores são obrigados contractualmente a proteger seus dados.

5. Armazenamento e Segurança

  • Dados armazenados em servidores seguros com criptografia (Supabase)
  • Senhas armazenadas com hash criptográfico
  • Comunicação criptografada via HTTPS/TLS
  • Acesso restrito a dados pessoais
  • Monitoramento de segurança contínuo
  • Dados mantidos enquanto a conta estiver ativa

6. Retenção de Dados

  • Dados de conta: mantidos durante a vigência da conta
  • Dados após exclusão: removidos permanentemente em até 30 dias
  • Dados de pagamento: retidos conforme exigência fiscal (5 anos)
  • Logs de acesso: mantidos por 12 meses para segurança

7. Seus Direitos (LGPD)

Conforme a LGPD, você tem direito a:

  • Acesso: Solicitar cópia dos seus dados pessoais
  • Correção: Corrigir dados incorretos ou desatualizados
  • Exclusão: Deletar sua conta e dados pessoais
  • Portabilidade: Exportar seus dados em formato estruturado
  • Revogação: Revogar consentimento a qualquer momento
  • Oposição: Se opor ao tratamento de dados para finalidades específicas

Para exercer seus direitos, acesse as configurações do App ou entre em contato com nosso DPO.

8. Menores de Idade

O App não é direcionado a menores de 14 anos. Não coletamos intencionalmente dados de menores. Se descobrirmos que coletamos dados de um menor, excluiremos imediatamente.

9. Cookies e Rastreamento

O App utiliza cookies essenciais para funcionamento (autenticação, preferências). Não utilizamos cookies de rastreamento de terceiros para publicidade.

10. Notificações Push

Você pode desativar notificações push nas configurações do seu dispositivo ou do App a qualquer momento.

11. Transferência Internacional

Alguns dados podem ser processados em servidores fora do Brasil (Expo, Google). Esses provedores garantem proteção conforme padrões internacionais de segurança.

12. Alterações nesta Política

Atualizaremos esta política conforme necessário. Alterações significativas serão comunicadas por e-mail ou notificação no App.

13. Contato e DPO

Para exercer seus direitos ou esclarecer dúvidas:

  • E-mail: dpo@novaixfitness.com
  • Suporte: suporte@novaixfitness.com
  • Encarregado (DPO): dpo@novaixfitness.com

Se não obtiver resposta satisfatória, você pode registrar reclamação na Autoridade Nacional de Proteção de Dados (ANPD): www.gov.br/anpd
