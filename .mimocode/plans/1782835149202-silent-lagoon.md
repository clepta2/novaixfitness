### 4. Motor Principal (`engine.ts`)
Orquestra traducao usando dicionario + regras + templates:

```typescript
import { createTranslator } from '../translation';

const t = createTranslator({ source: 'pt', target: 'en' });

// Traduz texto simples
t.translate('Salvar');           // 'Save'
t.translate('Ola mundo');        // 'Hello world'
t.translate('Treino de peito');  // 'Chest workout'

// Traduz com contexto
t.translate('Erro', { context: 'ui' });     // 'Error'
t.translate('Erro', { context: 'login' });  // 'Login failed'

// Traduz objeto inteiro
t.translateObject({ greeting: 'Ola', title: 'Treino' });

// Traduz projeto inteiro
t.translateProject('app/', { target: 'en' });
```

### 5. Modulo UI (`ui.ts`)
Substitui o i18n atual. Auto-detecta strings hardcoded:

```typescript
import { scanForStrings, generateTranslations } from '../translation/modules/ui';

// Escaneia arquivos .tsx e encontra strings hardcoded
const strings = await scanForStrings('app/');
// [{ file: 'app/login.tsx', line: 42, text: 'Entrar' }]

// Gera JSONs traduzidos automaticamente
await generateTranslations(strings, ['en', 'es']);
```

### 6. Modulo Comentarios (`comments.ts`)

### 9. Componentes React (`react/`)

