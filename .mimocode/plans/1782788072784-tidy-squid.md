# Plano: Comunidade NOVAIX Fitness v2

## Resumo

A comunidade atual tem base sólida (posts, likes, comentários, follows, gamificação, referrals) mas falta **experiência fotográfica, engajamento expressivo, gatilhos virais e um sistema de bônus coeso**. Este plano adiciona 3 camadas de melhorias em 8 semanas.

---

## Estado Atual

### O que funciona bem
- Posts com imagem/texto em tempo real (Supabase channels)
- XP gamificação (13 eventos, 5 níveis, ~30 conquistas)
- Referral com código NOVAIX +30 dias para ambos
- Feed com filtros, trending, busca de usuários
- Social Hub com 4 tabs (Feed, Desafios, Ranking, Forum)
- Notificações push + in-app
- Forum com categorias

### O que precisa melhorar

| Área | Lacuna | Impacto |
|------|--------|---------|
| Fotos | Só picker básico, sem filtros/progressão | Engajamento baixo |
| Reações | Só like binário | Interação limitada |
| Stories | Não existe | Retenção diária perdida |
| Check-in | Sem localização/academia | Sem prova social |
| Bônus | Espalhados (referral + XP) | Proposta de valor confusa |
| Moderação | Sem report/block | Risco de segurança |
| Grupos | Sem comunidades | Retenção fraca |
| Viral | Share básico, sem leaderboard de referral | Crescimento baixo |

## Sistema de Bônus Completo

### Bônus Diários
| Ação | XP | Limite |
|------|-----|--------|
| Check-in diário | 10-100 | 1x/dia (escalonado) |
| Postar foto | 15 | 3x/dia |
| Curtir 5 posts | 5 | 1x/dia |
| Comentar 3 posts | 10 | 1x/dia |
| Compartilhar treino | 20 | 1x/dia |
| Check-in academia | 5 | 1x/dia |

### Bônus Semanais
| Marco | Recompensa |
|-------|-----------|
| Postar 5 vezes | 50 XP + badge |
| Receber 25 reações | 75 XP |
| Comentar 15 vezes | 40 XP |
| Indicar 1 amigo | +30 dias |
| Completar desafio em grupo | 100 XP + badge |

### Marcos de Conquista
| Conquista | Recompensa |
|-----------|-----------|
| 100 posts | Badge "Veterano" + 500 XP |
| 500 likes recebidos | Badge "Celebridade" + 1000 XP |
| 50 indicações | Premium vitalício + Badge "Embaixador" |
| 30 dias de check-in | Badge "Dedicado" + 500 XP |
| Post no trending | Badge "Viral" + 200 XP |

## Regras de Implementação

1. Todas as novas tabelas precisam de **RLS policies** seguindo o padrão existente
2. Todas as novas features precisam de **eventos XP** nas constantes de gamificação
3. Novas tabelas com contadores precisam de **triggers Supabase**
4. Todos os componentes seguem **máx 200 linhas** (AGENTS.md)
5. Todos os novos componentes são exportados no **barrel** de `src/components/social/`
6. Dados em **src/data/**, constantes em **src/constants/**, serviços em **src/services/**
